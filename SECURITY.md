# Security / الأمان

This repository is a **frontend-only interactive demo**, not a production multi-user service. Passwords, authorization and data are simulated client-side; never use actual credentials, real incidents, or confidential content here.

هذه نسخة عرض فقط. لا تُدخل معلومات حساسة أو كلمات مرور حقيقية، ولا تعتمد على صلاحيات العرض لحماية بيانات المؤسسة. لإطلاق نسخة تشغيل فعلية يلزم Backend مصادق عليه وخادم وقاعدة بيانات مركزية واختبار أمني مستقل.

Never publish JSON backups, user records, environment files or private keys.
