# رِفد | RIFD

**منصة عرض تجريبية لإدارة الخدمات والبلاغات والأصول**، بواجهة عربية تدعم الجوال وتعمل دون مكتبات أو خادم API خارجي.

> ⚠️ **نسخة DEMO وليست نظام إنتاج.** جميع الحسابات والصلاحيات مُحاكاة داخل متصفح الزائر، والبيانات محلية ولا تتزامن بين المستخدمين. لا تُدخل بيانات عمل فعلية أو سرية، ولا تستخدم هذا الملف لخدمة مستخدمين فعليين.

![شعار رِفد](assets/RIFD-Logo.webp)

## التجربة من GitHub Pages

بعد إنشاء المستودع باسم **RIFD** ورفع محتوياته:

1. سير العمل يحاول تفعيل GitHub Pages تلقائيًا. إذا فشل، من **Settings → Pages → Build and deployment → Source** اختر **GitHub Actions**.
2. انتقل إلى **Actions** وتحقق من نجاح سير العمل **Deploy RIFD demo to GitHub Pages** (وقد يحتاج تشغيله يدويًا للمرة الأولى).
3. افتح عنوان Pages الذي يظهر في نتيجة النشر، وغالبًا يكون `https://anasmonti80-png.github.io/RIFD/` **بعد التفعيل الفعلي فقط**.

الواجهة متاحة للعرض من الجوال والمتصفح، لكن كل متصفح يحتفظ ببياناته المستقلة. لا توجد مزامنة بين الأجهزة.

## تشغيل محلي على ويندوز

1. اضغط **Code → Download ZIP**، ثم **Extract All**.
2. اضغط مرتين على **RIFD-START.bat** وأبقِ نافذة التشغيل مفتوحة.
3. يفتح الموقع غالبًا عبر `http://127.0.0.1:8765/`، وإن كان المنفذ مشغولًا يستخدم التالي حتى 8770.
4. لا تستخدم فتح HTML داخل نافذة معاينة ZIP أو تطبيق المحادثة؛ افتحه في Edge/Chrome أو عبر المشغّل المحلي.

تجربة المدير: `saad` / `Demo#2026ab`. زر اختيار الدور يتيح تجربة حسابات العرض الأخرى.

## المجلدات

| المسار | الاستخدام |
| --- | --- |
| `site/index.html` | موقع GitHub Pages (ملف HTML مستقل) |
| `RIFD.html` | نسخة التشغيل المحلي |
| `RIFD-START.bat` و `Run-RIFD.ps1` | تشغيل محلي على ويندوز دون تثبيت Node/Python |
| `assets/` | أيقونة PNG ونسختان من الشعار بصيغة WebP |
| `.github/workflows/deploy.yml` | فحص JavaScript ثم نشر Pages |
| `scripts/check.cjs` | فحص سلامة الملف، بدون اعتماديات خارجية |

## حفظ البيانات

- تُخزّن البيانات محليًا في **IndexedDB** مع بديل محلي محدود عند تعطلها.
- استخدم قسم **الإعدادات → النسخ الاحتياطي** لتنزيل نسخة JSON عند الحاجة.
- حذف بيانات الموقع، أو استخدام متصفح آخر، أو تغيير عنوان التشغيل قد يجعلك ترى بيانات مختلفة.
- ملفات النسخ الاحتياطية ليست مناسبة للنشر العام؛ لا ترفعها إلى GitHub.

## حدود النسخة الحالية

المشروع **ليس** خدمة متعددة المستخدمين ولا يطبّق صلاحيات خادم حقيقية. جاهزية الإنتاج تتطلب Backend وقاعدة بيانات مركزية ومصادقة حقيقية وتدقيقًا أمنيًا واختبارات حمل وأداء ونسخًا احتياطية مركزية.

## Privacy & security

Public source includes demo login credentials and sample records **by design**. It contains no operational secrets or real user data. Do not assume the demo role selector provides server-side authorization. Report vulnerabilities privately rather than including personal information in public issues.

**الترخيص:** لم يُضف ترخيص إعادة توزيع تلقائي؛ يبقى قرار ترخيص المشروع لصاحبه.
